# Chagent API

Chagent API is the core component of Chagent, responsible for handling all the API requests and responses.

## Installation

use [uv](https://docs.astral.sh/uv/getting-started/installation/) to install the dependencies.

```bash
uv sync
```

## Configuration

```bash
cp .env.example .env
```

## Usage

```bash
uv run main.py
```
